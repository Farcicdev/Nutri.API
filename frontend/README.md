# Frontend do NutriApp

Interface web do NutriApp, construída com React, TypeScript, Vite e Tailwind CSS.

A documentação completa do produto, arquitetura, segurança e instruções de execução está no [README principal](../README.md).

## Comandos

```bash
npm install
npm run dev
npm run lint
npm run build
```

Durante o desenvolvimento, o Vite encaminha as requisições iniciadas por `/api` para `http://localhost:8082`.
